# Сортировка универсальной таблицы

`DataTable` различает столбцы данных и действий. Для новых столбцов задавайте
`kind: 'data'` с исходным значением либо `kind: 'action'`. Заголовок и отображение
ячейки задаются отдельно от значения сортировки:

```tsx
const columns: TableColumn<Row>[] = [
  { id: 'grade', kind: 'data', heading: 'Оценка',
    value: row => row.grade, cell: row => row.grade ?? '—' },
  { id: 'open', kind: 'action', control: 'button', heading: 'Действия',
    cell: row => <button onClick={() => open(row)}>Открыть</button> },
];
```

Столбцы данных автоматически получают заголовок с переключением направления,
индикатор и `aria-sort`. Значение может быть строкой, числом, булевым значением или
`Date`. Сложные объекты преобразуются явным `value`; React-разметка не анализируется.
Для особого порядка можно задать `compare`. Пустые строки, `null`, `undefined`,
нечисловые числа и недопустимые даты остаются в конце в обоих направлениях.
Равные значения сохраняют исходный порядок; входной массив не изменяется.

`control: 'picker' | 'slider' | 'button'` описывает контрол ячейки. Это метаданные,
а не автоматический рендерер. Контрол со значением может оставаться столбцом данных
и сортироваться; столбец только с действием не сортируется.

Для цепочки критериев используйте `sortTableRowsByCriteria` из `table-sort.ts`:
массив `TableSort` задаёт приоритет сверху вниз. При равенстве, в том числе двух
пустых значений, сравнение продолжается по следующему критерию. Окончательные
равенства сохраняют исходный порядок. Прежний `sortTableRows` сохраняет контракт
одного критерия.

Без пагинации `DataTable` управляет сортировкой самостоятельно. При пагинации
страница хранит `TableSort`, вызывает `sortTableRows(filtered, columns, sort)` до
`slice` и передаёт таблице `sort` и `onSortChange`. При наличии этого callback
таблица не переставляет полученную страницу повторно. На изменение сортировки
страница обычно сбрасывает номер страницы. `sortingDisabled` блокирует заголовки.

Индексы в `cell`, `getRowKey`, `rowLabel` и `renderAfterRow` соответствуют исходным
входным строкам, даже после внутренней сортировки. Привязывайте действия к строке
или её устойчивому ID, а не к видимому месту на экране.

Столбцы без `kind` работают в прежнем режиме: их заголовки и внешняя сортировка
сохраняются. Таблицы учеников и ДЗ сохраняют прежний интерфейс.

В «Мой урок» кнопка «Настройки таблицы» открывает окно сортировки. Можно добавить
критерии по имени, присутствию, контрольной, работе на уроке, топкойнам и средней,
выбрать направление, удалить или переместить критерий кнопками вверх/вниз.
Один столбец участвует в цепочке один раз. Изменения применяются сразу ко всем
найденным строкам до страниц по 25 учеников. Нулевая средняя — число, а не пустота;
запятая в числовых строках поддерживается. Пока средние загружаются или недоступны,
они считаются пустыми для сортировки. Присутствие сравнивается в порядке:
отсутствует, присутствует, опоздал; неизвестный статус идёт в конце.

Заголовок делает столбец первым критерием и переключает его направление,
сохраняя остальные критерии. Стрелка и номер обозначают направление и приоритет;
`aria-sort` установлен только у первого критерия. Сброс возвращает имя по возрастанию;
удаление всех критериев возвращает исходный порядок. Сортировка сбрасывает страницу,
сохраняет выбранные ID и не меняет черновик. Настройки не сохраняются между сессиями;
смена контекста урока закрывает окно и возвращает сортировку по умолчанию.
