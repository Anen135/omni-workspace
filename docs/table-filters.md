# Фильтры и пагинация DataTable

Таблица принимает полный набор строк, описания столбцов и только те параметры
фильтрации, которые нужны конкретному экрану:

```tsx
<DataTable
  rows={rows}
  columns={columns}
  getRowKey={row => row.id}
  filters={[
    { id: 'name', label: 'Имя', kind: 'text', value: row => row.name },
    { id: 'group', label: 'Группа', kind: 'select', value: row => row.group },
    { id: 'grade', label: 'Оценка', kind: 'number', value: row => row.grade },
    { id: 'date', label: 'Дата', kind: 'date', value: row => row.date },
    { id: 'active', label: 'Активен', kind: 'boolean', value: row => row.active },
    { id: 'filled', label: 'Оценка заполнена', kind: 'presence', value: row => row.grade },
  ]}
  defaultSort={{ columnId: 'name', direction: 'ascending' }}
  pagination={{ pageSize: 25, pageSizeOptions: [10, 25, 50, 100] }}
/>
```

`value` явно извлекает значение из строки, включая вложенное или вычисляемое поле.
Фильтр не обязан соответствовать видимому столбцу. React-разметка не анализируется.
Все заполненные условия объединяются через AND; неизвестные ключи состояния
игнорируются. Встроенного конструктора OR-групп или исполняемых выражений нет.

- `text`: поиск подстроки без учёта регистра, внешние пробелы поиска удаляются.
- `select`: точное выбранное значение. Варианты берутся из всех входных строк,
  независимо от действующих фильтров. Можно задать `options: [{ value, label }]`.
- `number`: включительный диапазон, одна или обе границы могут отсутствовать.
- `date`: включительный календарный диапазон. Строки — корректный ISO-день или
  ISO timestamp с сохранением указанного в нём дня; `Date` сравнивается по UTC-дню.
- `boolean`: все, да или нет; `false` считается значением.
- `presence`: все, пустые или заполненные. `0` и `false` не считаются пустыми;
  `null`, `undefined`, пустая строка, NaN и недопустимая дата считаются пустыми.

Порядок обработки: фильтрация → сортировка → пагинация → отображение. Фильтры,
сортировка и размер страницы сбрасывают номер страницы. При уменьшении данных
номер ограничивается последней доступной страницей. Действия и раскрытые строки
сохраняют связь с исходными строками, а не с их видимыми позициями.

`filterState` и `onFiltersChange` передаются вместе для внешнего управления;
без этой пары таблица хранит условия сама. Состояние — объект по `id` фильтра:
строка либо `{ from: string, to: string }` для диапазона. Можно отдельно использовать
`filterTableRows` и `TableFilters` для нестандартного экрана.

Существующая пара `sort` + `onSortChange` означает внешнюю сортировку: таблица
не переставляет строки повторно. При внутренней пагинации такому экрану всё равно
нужно передавать полный отсортированный набор. Без этой пары таблица сортирует сама.

При включении внутренних фильтров или страниц заголовок выбора охватывает только
доступные строки по текущим фильтрам, на всех страницах. Второй аргумент
`selection.onToggleAll(checked, filteredRows)` содержит эти строки. Используйте
именно его для массового выбора. Выбор скрытых строк автоматически не удаляется.

Без `filters` и `pagination` прежний режим сохраняется: экран может передавать
уже отфильтрованную страницу и собственные элементы управления. Рабочие экраны
Omni могут сохранять собственную пагинацию; общий режим демонстрируется на странице UI-тестов.

## Фильтры в «Мой урок»

Кнопка «Настройки таблицы» открывает общий для сортировки и фильтров диалог.
Добавьте фильтр, выберите поле, условие и значение. В каждой группе все условия
связаны через И; несколько групп связаны через ИЛИ. Число групп и условий
не ограничено интерфейсом, дальнейшей вложенности нет. Поиск по имени действует
дополнительно ко всему выражению. Изменения применяются сразу.

- Имя: содержит / не содержит текст без учёта регистра.
- Присутствие: равно / не равно выбранному статусу.
- Контрольная, работа на уроке, средняя и топкойны: равно, не равно, больше,
  не меньше, меньше, не больше, включительный диапазон с одной или двумя границами.
- Для всех полей доступны «Пусто» и «Заполнено». Нулевая оценка или средняя —
  заполненное значение. Топкойны нормализуются по правилам урока: `0`, `4`,
  пустое значение и `null` обозначают отсутствие награды (число 0).

Числа можно вводить с точкой или запятой. Пустой текст условия, неверное число,
диапазон без границ и перепутанные границы показывают ошибку. Пока есть ошибка
хотя бы в одном условии, выборка пуста, в том числе при наличии других ИЛИ-групп.
Для отрицательных сравнений пустые значения не подходят: их выбирают отдельным
условием «Пусто». Если фильтр использует среднюю, её загрузка или ошибка временно
дают пустую выборку с пояснением, пока средние снова не станут доступны.

Примеры:

1. «Присутствие равно присутствует» И «Работа на уроке пуста».
2. «Средняя оценка в диапазоне 8–10,5».
3. Первая группа «Присутствие равно присутствует», вторая ИЛИ-группа
   «Присутствие равно опоздал».

Фильтры учитывают текущий черновик и все страницы. Затем применяются поиск,
цепочка сортировок и пагинация. Счётчики и область «все по фильтрам» используют
тот же набор строк. Изменение поиска или условий очищает выбор; сортировка и
страницы его сохраняют. Если строка скрывается из-за правки черновика или обновления
данных, её ID исключается из выбора и не выбирается снова автоматически.
Фильтры сбрасывают страницу, а уменьшение набора ограничивает её допустимым номером.

Условия можно редактировать и удалять; удаление последнего условия удаляет группу.
Кнопка «Сбросить фильтры» доступна в диалоге и рядом с кнопкой настройки при активных
фильтрах. Сброс фильтров сохраняет поисковый запрос и сортировку. Смена контекста
урока закрывает окно и сбрасывает фильтры. Настройки хранятся только в памяти экрана.
Остальные потребители `DataTable` сохраняют прежнюю модель фильтрации.
