# Локальный буфер сохранения урока

Буфер работает в расширении Chromium. Только нажатие «Сохранить» (и подтверждение
темы, если оно требуется) разрешает поместить изменения в очередь. Обычные правки
без нажатия «Сохранить» автоматически не отправляются.

- Очередь хранится в закрытом хранилище расширения; сайт и content scripts не имеют
  прямого доступа. Сохраняются контекст занятия, идентификаторы, изменения и исходные
  значения, без учётных данных, фотографий и ответов сервера.
- После входа автоматически продолжаются только сохранения, которые заведомо не
  дошли до записи. Проверяются аккаунт, филиал, дата, группа, пара, занятие и исходные
  значения. Открывать прежнее занятие для такой отправки не обязательно.
- Перед каждой записью очередь получает отметку о неопределённом результате.
  Потерянный ответ не даёт разрешения на автоматический повтор. Подтверждённые
  изменения удаляются из очереди по частям.
- Иконка выгрузки обозначает сохранённый буфер. Ручной повтор сначала перечитывает
  урок и исключает уже применённые изменения. Конфликты остаются для проверки.
- Неопределённую выдачу материалов вместе с темой повторять нельзя: одно совпадение
  названия темы не подтверждает выдачу ДЗ или практики. Нужно проверить результат
  в Omni и отменить устаревший черновик перед новой отправкой.
- Другой аккаунт или филиал не получает чужие изменения. Очередь защищена от
  параллельной отправки разными вкладками и устаревших подтверждений.
- Пределы: 50 занятий, 1 МиБ, семь дней с последнего обновления записи. Истёкшие
  записи не отправляются. Ошибка хранения останавливает отправку и показывает тост.
- «Отменить черновик» удаляет и его сохранённый буфер.

Сообщения об ошибках показываются отдельным тостом с повтором и закрытием;
автоматически скрываются через восемь секунд. Скрытие тоста не удаляет очередь.

Проверки: `npm test`, `npm run build:extension`; затем
`$env:OMNI_DRAFT_RECOVERY_ONLY='1'; node tests/extension-browser.mjs` в PowerShell
для сценариев восстановления на вымышленных данных. Обычный
`npm run test:extension-ui` проверяет полный сценарий расширения.
