# Экран загрузки и входа расширения

Расширение показывает небольшой экран загрузки на `document_start`, до отрисовки
содержимого Omni. Основной интерфейс загружается отдельно и принимает тот же
Shadow DOM host. Оригинальная страница остаётся в DOM для официальных скриптов,
CSRF и восстановления; её содержимое не удаляется.

На стандартной странице входа показывается собственная форма. Она использует
существующий запрос `/auth/login` в origin Omni, с его CSRF и cookies. Пароль
очищается из поля до ожидания ответа, при уходе и размонтировании; в React state,
сообщения расширения и его хранилище он не попадает. Отменённый запрос не может
сохранить поздний session hash или переключить интерфейс.

После успешного входа открывается `/`. Рабочее пространство появляется только
после существующей проверки профиля Omni; восстановление черновиков выполняется
прежним механизмом с проверкой аккаунта, филиала и занятия.

Оригинальный интерфейс используется при CAPTCHA/DDoS-проверке, OTP, смене пароля,
неизвестной форме или отсутствии CSRF. «Открыть официальный вход» доступен также
вручную. Выбор запоминается только флагом `omni.native-login` в sessionStorage
вкладки и снимается после подтверждённого подключения.

Если основной интерфейс не запускается за 30 секунд, загрузочная завеса удаляется.
Атрибуты доступности и inert оригинальных элементов восстанавливаются. При возврате
из кеша браузера подключение проверяется заново. Никакие проверки Omni не обходятся.

Проверки на вымышленных учётных данных:

```text
node --test tests/extension-login.test.mjs tests/login.test.mjs
npm run build:extension
node tests/extension-login-browser.mjs
```

Браузерный сценарий проверяет раннюю завесу при задержанной загрузке оригинала,
свою форму, CSRF/cookies, двойную отправку, отмену, отсутствие пароля в сообщениях
и хранилище, штатный профиль и восстановление оригинальных защитных форм.
События pagehide/pageshow для проверки жизненного цикла моделируются явно;
это не доказательство помещения страницы в настоящий back/forward cache.
Реальный вход и текущую разметку Omni без действующей сессии эти fixtures не доказывают.
