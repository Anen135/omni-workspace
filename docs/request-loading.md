# Загрузка и обновление данных

Досье и каталог материалов сохраняют загруженные данные при переходах между разделами. Эти данные находятся только в памяти открытого рабочего пространства. Смена аккаунта, филиала или сессии очищает соответствующее состояние. Общая кнопка «Обновить» перечитывает снимок и сбрасывает сохранённые данные разделов.

Расчёт дохода сначала загружает недели для месячных показателей и расчётного периода выплаты. «Загрузить историю за год» добавляет недостающие недели для годового показателя. Полностью загруженное датированное расписание используется повторно. Неполные недели сохраняют известные занятия и показывают пропуски. По отдельной кнопке можно повторить только недостающие, неполные и ошибочные недели; «Обновить расчёт» заново читает весь выбранный диапазон. Отсутствующие данные не заменяются нулями или копиями недель.

Проверенные списки студентов используются совместно в уроке, ДЗ и разделе студентов. ДЗ запрашивает группы из своей очереди; если группа работы не определена однозначно, используется полный список доступных групп. «Обновить группу» перечитывает выбранную группу. Сохранение урока или оценки ДЗ, включая неподтверждённый результат, сбрасывает списки студентов и статистику досье.

«Обновить работы» перечитывает только очередь ДЗ. При ошибке сохраняются ранее подтверждённые оценки и запрет нового сохранения до успешного обновления. При смене фильтров материалов переиспользуются справочники форм и типов. Явное обновление каталога перечитывает и справочники.

Проверки аккаунта при чтении и сохранении, проверки исходных значений и подтверждение результата записи сохранены. Кеш не служит подтверждением личности и не используется для обхода проверок записи.

## Команды чтения

`homework-queue` принимает только `{ accountId: string }` с положительным числовым идентификатором и возвращает `{ account, newHomework: Section }`. Аккаунт проверяется перед чтением `/homework/get-new-homeworks` и после него. Ошибка раздела сохраняется в `Section.error`; клиент не снимает блокировку оценивания при ошибке.

`materials-catalog` поддерживает необязательный `includeMetadata: boolean`, по умолчанию `true`. Значение `false` исключает запросы форм и типов материалов; возвращаемые разделы `forms` и `types` пусты, клиент сохраняет ранее загруженные справочники. Остальные фильтры и ответ совместимы с прежним вызовом.
