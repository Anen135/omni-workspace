# Иконка приложения

Файл: [`public/icon.png`](../public/icon.png). Используется как favicon, иконка для домашнего экрана и иллюстрация в README.

Создана встроенным инструментом генерации изображений с помощью навыка imagegen. Новая растровая иконка: буква O из двух страниц книги, лавандовая основа и мятный акцент. Официальные логотипы академии и браузеров не использованы.

Финальный промпт:

```text
Use case: logo-brand
Asset type: square raster application icon for Omni Workspace, an independent teacher dashboard for schedules and lessons.
Primary request: create a polished original app icon: a bold open circular O made from two curved book-page ribbons, with a small mint green dot near the upper right opening, suggesting learning and a calm organized workspace.
Style/medium: minimal crisp graphic with very subtle soft depth, readable silhouette at favicon size.
Composition/framing: single centered mark, large and balanced, lavender rounded-square tile filling the square canvas, modest safe margin.
Color palette: violet and lavender with an off-white mark and a small muted mint accent, matching a light purple teacher dashboard.
Constraints: 1024 by 1024 square, no text, no watermark, no mockup, no official academy or browser logos, no decorative objects.
```
