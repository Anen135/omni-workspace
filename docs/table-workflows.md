# Массовое редактирование таблиц и топкойны

## Единое значение в столбце

В таблицах «Мой урок» и домашних заданий используется общий редактор:

1. В уроке раскройте «Массовое редактирование». Выберите редактируемый столбец и единое значение.
2. Выберите область: **выбранные строки** либо **все по текущим фильтрам**. Второй вариант охватывает все страницы, а не только открытую.
3. Проверьте количество получателей и недоступных строк. Если среди целей есть недоступные строки, операция блокируется целиком; скрытого пропуска нет.
4. Нажмите кнопку применения. Выбор конкретных строк доступен галочками; галочка в заголовке выбирает доступные строки по фильтрам на всех страницах.

При изменении фильтра выбор очищается. Сортировка и переход между страницами его сохраняют. Перечитывание набора данных или смена урока сбрасывает старый выбор; локальные правки черновика урока его сохраняют.

В **«Мой урок»** доступны контрольная, работа на уроке, присутствие и топкойны. Оценки имеют существующий технический диапазон 1–100, значение по умолчанию — 12; допустимую шкалу определяет Omni. Массовая правка сначала попадает в черновик. Чтобы отправить её, проверьте результат и нажмите общую кнопку **«Сохранить»**. Массовые топкойны проверяются по итоговому состоянию всего урока, включая скрытых учеников: при превышении лимита в черновик не попадёт ни одна строка операции.

В **ДЗ** редактируется оценка 1–12, максимум 100 работ за операцию. Кнопка «Поставить оценку» использует прежнее подтверждение записи и перечитывание. Если подтверждена только часть работ, интерфейс показывает именно подтверждённую часть. Автоматического повторения неопределённой записи нет. Результат старой операции не должен показываться как результат нового набора работ.

## Вычисляемые оценки в «Мой урок»

Целевые столбцы — «Работа на уроке» и «Контрольная». Способ заполнения выбирается
отдельно от столбца; прежних пунктов «средняя ↑» в списке столбцов больше нет.

- **Одинаковое значение**: введите целую оценку 1–100.
- **Поле каждого ученика**: выберите среднюю, работу на уроке или контрольную.
  Значение каждого получателя округляется отдельно.
- **Среднее по области**: выберите источник, затем независимо укажите область
  расчёта и получателей. Доступны выбранные ученики, все по фильтрам на всех
  страницах и вся группа. По умолчанию используются выбранные ученики.

Округление по умолчанию — вверх; доступны вниз и до ближайшего целого с округлением
0,5 вверх. Источники могут содержать точку или запятую. Для средних 8, 10, 11
агрегатный режим с округлением вверх даёт 10 каждому получателю; индивидуальный —
8, 10, 11 соответственно. Расчёт использует единый снимок данных с текущим
черновиком; изменение первых строк не влияет на расчёт следующих.

Пустой источник по умолчанию блокирует расчёт. Можно явно выбрать исключение
пустых: в агрегатном режиме они не входят в знаменатель, в индивидуальном их
получатели остаются без изменения. Причина показана для каждой строки. Непустое
некорректное значение, ноль или источник вне 1–100 блокирует весь расчёт даже
при разрешённом пропуске пустых. Ошибка загрузки средних также блокирует расчёт
по средней. Если все источники пусты, агрегат вычислить нельзя.

Заполненные оценки, включая черновик, по умолчанию сохраняются. Чтобы заменить
их, включите соответствующий флажок. Технический диапазон оценок урока остаётся
1–100; он отличается от шкалы алгоритма топкойнов и шкалы ДЗ. Значения не
обрезаются до диапазона автоматически.

«Заполнить столбец» для оценок открывает предварительный результат: источник,
область расчёта, количество получателей, округление, политики и «было → станет».
Закрытие окна ничего не меняет. «В черновик» применяет все допустимые изменения
атомарно; отправка происходит только общей кнопкой «Сохранить». Если данные,
контекст урока, выбор или настройки изменились, старый результат применить нельзя —
закройте окно и рассчитайте заново. Исходные оценки и проверки сохранения сохраняются.

Присутствие и единые топкойны по-прежнему используют существующее массовое действие;
вычисляемые способы доступны только для оценок. Поведение массовой записи ДЗ не меняется.

## Предложение топкойнов

Над таблицей урока нажмите **«Распределить топкойны»**: одно нажатие рассчитывает
награды по актуальным данным и добавляет результат в черновик. Область всегда —
**вся группа**, включая скрытых поиском и фильтрами учеников. Область действия
и число изменяемых строк доступны в подсказке. Отправка в Omni — только общей кнопкой «Сохранить».

Шестерёнка **«Настройки распределения топкойнов»** открывает отдельное окно.
Выберите источник балла: работа на уроке, контрольная, средний балл либо среднее
арифметическое работы на уроке и среднего балла. Последний режим требует оба
значения. По умолчанию используются работа на уроке, минимум 7 и сохранение
ручных наград. Параметры действуют в текущем уроке, хранятся в памяти и сбрасываются
при смене контекста; между сессиями они не сохраняются.

Расчёт поддерживает шкалу 1–12. Пустые, некорректные и выходящие за шкалу значения не считаются нулём. Минимальный балл по умолчанию — 7, его можно изменить. Участвуют присутствующие и опоздавшие ученики.

При достижении выбранного минимума действуют потолки награды:

| Балл | Максимум топкойнов |
| --- | ---: |
| Ниже 9 | 1 |
| От 9 до значения ниже 11 | 2 |
| От 11 | 3 |

Алгоритм — адаптация порогового и пропорционального распределения под бюджет 5, а не официальная формула олимпиады. Вес кандидата: `(балл − минимум + 1)²`. Сначала вычисляются пропорциональные доли с потолками. Затем выбираются целые награды в пределах бюджета: большее достижимое распределение, затем меньшая ошибка относительно долей, затем приоритет более высоких баллов. Равные баллы рассматриваются одной группой и получают одинаковое количество; кандидат с меньшим баллом не получает больше кандидата с большим.

Примеры для полного бюджета и минимума 7:

| Баллы | Топкойны | Остаток |
| --- | --- | ---: |
| 12, 10, 7 | 3, 2, 0 | 0 |
| 12, 11, 10 | 2, 2, 1 | 0 |
| 12, 8 | 3, 1 | 1 |
| 12, 12 | 2, 2 | 1 |
| 12, 12, 12 | 1, 1, 1 | 2 |
| Шесть одинаковых подходящих баллов | По 0 | 5 |

Остаток допускается: например, 5 целых монет невозможно поровну положительно распределить между шестью одинаковыми кандидатами. Алгоритм не выбирает произвольного победителя среди равных и не повышает слабому результату уровень только ради расходования бюджета.

По умолчанию сохраняются уже выданные награды и все ручные изменения, включая снятие награды в черновике. Они занимают часть бюджета; равенство автоматических наград относится к кандидатам текущего расчёта, а не к зафиксированным вручную решениям.

Для пересчёта включите **«Заменить существующие награды и ручной черновик»**. Замена касается присутствующих/опоздавших с корректным баллом. У них награда ниже минимума может быть снята; награды отсутствующих и учеников без корректного балла сохраняются и учитываются в бюджете. Неизвестные награды или некорректные/повторяющиеся ID блокируют расчёт.

В окне настроек видна краткая сводка бюджета. «Подробности расчёта» раскрывают
таблицу «сейчас → расчёт» и причины для каждого ученика. Просмотр и изменение параметров ничего не применяют.
Закройте окно и нажмите основную кнопку: расчёт выполняется заново, старый
предварительный результат не используется. Изменения сохраняют проверки
присутствия и итогового бюджета всего урока. Повторный запуск по умолчанию
сохраняет награды, уже добавленные в черновик.

Если расчёт заблокирован или подходящих изменений нет, причина показана рядом
с кнопкой; настройки остаются доступны. Для источников со средним баллом
загрузка или ошибка средних блокирует применение. Отказ добавления в черновик
показывается рядом с действием, автоматических повторов нет. После применения
проверьте результат в таблице и нажмите **«Сохранить»** для отправки в Omni.

## Основа интерфейса и расчёта

Изучены [Prisma Studio](https://github.com/prisma/studio/blob/main/FEATURES.md) и [массовое редактирование AG Grid](https://www.ag-grid.com/react-data-grid/cell-selection/): использованы принципы явного выбора области, колонки и подтверждения. Новая библиотека таблиц не добавлялась. Общие компоненты находятся в `src/components/data`; страницы задают колонки, доступность и доменные действия.

Для наград изучены [правила IOI](https://github.com/ioi/regulations/blob/main/IOI_Regulations.tex) и [правила IMO](https://www.imo-official.org/assets/documents/imo-general-regulations.pdf). Их квоты медалей не переносятся на учебные топкойны буквально: наша политика сохраняет пороги, равенство баллов и ограничение бюджета.

Копирование с прошлой пары открывается кнопкой «Скопировать с прошлой пары» в контексте урока. В модальном окне явно загрузите источник, выберите категории и проверьте предпросмотр. Закрытие сбрасывает источник и параметры, не меняя черновик. «В черновик» применяет выбор; отправка в Omni — через «Сохранить».

## Итоговый сценарий урока

1. Выберите урок в контексте занятия или откройте его из расписания.
2. Через «Настройки таблицы» настройте фильтры и приоритеты сортировки. Поиск и фильтры действуют до сортировки и разбиения на страницы. Смена фильтров сбрасывает выделение; сортировка сохраняет ID выбранных учеников.
3. Раскройте «Массовое редактирование», укажите получателей и способ заполнения оценок. Для среднего по области источник и получатели выбираются отдельно. Проверьте обязательный предпросмотр и нажмите «В черновик».
4. При необходимости распределите топкойны. Эта операция всегда учитывает всю группу. Шестерёнка открывает параметры, а подробности расчёта раскрываются отдельно.
5. Проверьте черновик и нажмите «Сохранить». Ошибки и конфликт исходных данных требуют проверки результата; автоматической повторной отправки нет.

Общее количество учеников показано в заголовке. Число найденных появляется при поиске/фильтрах, число выбранных — при выделении. Индикатор топкойнов показывает расход общего бюджета. Пояснения доступны через подсказки и «Справочник»; они открываются также с клавиатуры и нажатием.
