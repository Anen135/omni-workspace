# Источники файлов

Домены и каталоги превью задаются только в `config/file-sources.json`.
Чтобы разрешить новый источник, добавьте в массив `sources` запись:

```json
{
  "host": "files.example.com",
  "pathPrefixes": ["/academy/"]
}
```

Указывайте точный домен без протокола и порта. Каталоги начинаются и заканчиваются
`/`; маски, параметры запроса и переходы `..` не поддерживаются. Для адресов вида
`/api/v1/files/<идентификатор>` можно указать `"fileId": true`: после каталога
тогда разрешены только буквы, цифры, `_` и `-`, без вложенных каталогов.

HTTPS, отсутствие учётных данных в URL, допустимый каталог и тип содержимого
проверяются отдельно от разрешений браузера. Неправильный конфиг отклоняется:
сборка расширения завершается ошибкой, а desktop не разрешает загрузку превью.

После изменения:

- Расширение: `npm run build:extension`, затем перезагрузите расширение и страницу
  Omni. Разрешения для источников автоматически попадают в собранный manifest.
- Веб: перезапустите dev-сервер либо пересоберите приложение.
- Desktop: пересоберите приложение; этот же JSON включается в его ресурсы.

Не редактируйте `dist-extension/manifest.json` и другие результаты сборки вручную.
