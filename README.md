# Omni Workspace · Beta

Компактное рабочее пространство преподавателя Академии TOP — **расширение браузера**, работающее через вашу сессию официального Omni.

[Скачать бета-версию](https://github.com/Anen135/omni-workspace/releases/tag/v0.3.0-beta.1) · [Сообщить об ошибке](https://github.com/Anen135/omni-workspace/issues) · [История изменений](CHANGELOG.md) · [GPL-3.0-only](LICENSE)

> Независимый, неофициальный проект. Бета-версия может содержать ошибки. Учебные данные доступны для чтения: выставление оценок, отметка посещаемости и отправка заданий в Omni **не реализованы**.

## Установка

1. Скачайте `omni-workspace-0.3.0-beta.1-extension.zip` из Releases и распакуйте в постоянную папку.
2. Откройте страницу управления расширениями Chromium-браузера (Chrome, Edge или Opera), включите режим разработчика.
3. Нажмите «Загрузить распакованное расширение» и выберите папку, непосредственно содержащую `manifest.json`.
4. Нажмите значок Omni Workspace, затем «Открыть официальный вход».
5. Войдите на официальном сайте Omni. Не закрывайте созданную вкладку: через неё загружаются данные.

**Node.js, EXE и локальный сервер пользователю не нужны.** Интерфейс включён в расширение, GitHub Pages не участвует в подключении. Автоматические проверки установки выполняются в Chromium; совместимость конкретной версии Opera или Edge может отличаться.

При обновлении замените распакованные файлы, нажмите «Перезагрузить» на карточке расширения и заново откройте интерфейс через его значок. Обычное обновление вкладки не обновляет фоновый обработчик.

## Возможности

- **Расписание:** недельная временная сетка и список, выбор даты, отдельные колонки для пересекающихся занятий. Если время не получено, оно не выдумывается.
- **Мой урок:** текущая пара, ученики, доступные оценки и посещаемость.
- **Ученики:** выбор группы, поиск, сортировка по имени, постраничный просмотр и карточки.
- **Домашние задания:** реальные ответы, тема и предмет, поиск, фильтр групп при наличии данных и файлы.
- **Материалы:** каталог методичек до начала занятия, формы обучения, направления, методпакеты, поиск и выданные файлы.
- **Превью:** сворачиваемые изображения и PDF, миниатюры при наведении. Для неподдерживаемых файлов остаётся ссылка на оригинал.
- **Работаю от имени:** переключение только между преподавателями, разрешёнными текущей сессии Omni.
- **Сменить аккаунт:** подтверждённый выход и ручной вход другим логином на официальном сайте.
- **Быстрые действия:** скрытая панель справа с открытием Omni, экспортом снимка и печатью расписания.

Доступность данных зависит от прав аккаунта и ответов Omni. Демонстрация открывается отдельно и не подменяет реальные данные.

## Сессия и безопасность

Пароли вводятся только в официальной вкладке, не сохраняются в расширении или репозитории. Сессия общая для вкладок Omni в текущем профиле браузера: смена преподавателя или аккаунта влияет и на них. При переключении старые данные интерфейса очищаются.

Расширение использует ограниченный набор команд, проверяет источник сообщений и доступных преподавателей. Чтение выполняется изолированным адаптером; переключение преподавателя использует штатную функцию очистки сессии Omni. Произвольные URL и скрипты через сообщения не принимаются. Расширение не обходит авторизацию, права доступа и проверки браузера.

Разрешения: `scripting`, `storage`, официальный домен Omni и два файловых хоста. В `storage.session` сохраняется ID служебной вкладки. Превью файлов ограничены по размеру (8 МБ); при ошибке можно открыть оригинал.

Экспорт JSON может содержать персональные данные. Не прикладывайте его к публичным Issues. Локальные профили, выгрузки, тестовые скриншоты и заметки агента исключены через `.gitignore`. История Git сохраняет ранее закоммиченные файлы.

## Если что-то не работает

- **Команда не поддерживается / обработчик устарел:** перезагрузите именно расширение и откройте новую вкладку интерфейса.
- **Повторный вход или проверка браузера:** завершите её в официальной вкладке.
- **Пустые группы, оценки или материалы:** проверьте выбранного преподавателя и данные в оригинальном Omni.
- **Превью не загружается:** откройте оригинал. Файловый сервер может ограничивать доступ или размер файла превышает лимит.
- **Смена аккаунта не завершилась:** выполните выход и вход в официальной вкладке вручную, затем обновите подключение.

При сообщении об ошибке укажите версию расширения и браузера, ОС, шаги воспроизведения и обезличенный текст ошибки. Не публикуйте пароли, cookies, токены и сведения учеников.

## Разработка

Node.js 24, npm и Git:

```sh
git clone https://github.com/Anen135/omni-workspace.git
cd omni-workspace
npm ci
npm test
npm run build:extension
npx playwright install chromium
npm run test:extension-ui
```

Результат сборки — `dist-extension/`. Его можно загрузить как распакованное расширение. Браузерный тест использует отдельный временный профиль и вымышленные ответы, не обращается к реальному аккаунту.

Дополнительные UI-проверки (требуется установленный Edge): `npm run test:workspace-ui`, `npm run test:materials-ui`, `node tests/login-browser.mjs`. Скриншоты сохраняются в `tmp/`.

| Каталог | Назначение |
| --- | --- |
| `src/` | React/TypeScript-интерфейс, расписание, таблицы и превью |
| `extension/` | Manifest V3, обработчик команд, сборка |
| `desktop/omni-agent.mjs` | Общий адаптер запросов, включаемый в расширение |
| `server/` | Общая валидация и прежний локальный адаптер |
| `tests/` | Модульные и браузерные проверки |

Desktop-оболочка и локальный сервер оставлены как экспериментальные варианты, но не входят в установочный пакет бета-расширения.

**Ветки:** `main` — опубликованная бета-версия, `develop` — дальнейшая разработка. Каждый push в эти ветки проходит CI и сборку расширения; готовый пакет доступен в артефактах Actions. Версионные выпуски публикуются отдельно в Releases. Pages-демо и desktop-сборка запускаются только вручную и не являются основным продуктом.
