# Расширение Omni Workspace — Beta

Бета-версия из ветки `main`, дальнейшая разработка — `develop`. Интерфейс поставляется внутри расширения Manifest V3. Не нужны EXE, WebView2, Node.js или сервер на компьютере пользователя. Node.js нужен только разработчику для сборки. Код расширения обновляется заменой пакета, не скачивается с сайта.

## Установка для тестирования

```powershell
npm ci
npm run build:extension
```

1. В Opera откройте `opera://extensions`, в Chrome — `chrome://extensions`, в Edge — `edge://extensions`.
2. Включите режим разработчика и выберите «Загрузить распакованное расширение».
3. Выберите папку `dist-extension` в проекте. Если получили ZIP, сначала распакуйте его.
4. Нажмите значок расширения: оно откроет или активирует вкладку `https://omni.top-academy.ru/`.
5. Завершите официальную проверку браузера и вход в этой вкладке. После входа наш интерфейс появится здесь автоматически; отдельная вкладка интерфейса больше не нужна.
6. При обновлении расширения перезагрузите его на странице управления расширениями, затем обновите вкладку Omni.

Интерфейс встроен непосредственно в документ Omni и изолирован от его стилей. Оригинальное приложение скрывается, но его служебный код сохраняется для штатного переключения преподавателя. Страница входа и проверка браузера остаются официальными.

Автотест запускается на Chromium. Ручная совместимость Opera/Edge и реальный вход конкретного аккаунта требуют отдельной проверки. Firefox не поддерживается этим прототипом.

## Разрешения и границы

В текущем коде расписание открывает конкретную дату и пару в «Мой урок». Посещаемость и оценки за контрольную/работу на уроке можно изменять без клиентского ограничения на прошедшее или будущее занятие. Оценки записываются фиксированной командой `/presents/set-mark`; проверяются аккаунт, дата, группа, пара, расписание, ученик, ID посещения и прежняя оценка. Успех подтверждается перечитыванием. Реальные ограничения шкалы и периода остаются за сервером. Нет автоматических повторов записи, удаления оценки или создания фиктивных посещений.

- `scripting`: упакованный адаптер чтения и посещаемости в основной фрейм вкладки `omni.top-academy.ru`, в изолированном мире расширения. Переключение преподавателя выполняется отдельной фиксированной функцией в MAIN: ей нужен доступ к штатной очистке сессии Omni.
- `storage`: хранятся служебная ревизия сессии и сообщение о неподтверждённом выходе для конкретной вкладки. Ревизия позволяет сбросить устаревшие данные при переключении аккаунта или преподавателя. Пароли, cookies и учебные данные расширение туда не записывает.
- Доступ к Omni и файловым хранилищам Academy для запросов и превью. Match-пути host_permissions не ограничивают доступ внутри хоста; дополнительная проверка путей есть в коде.
- Нет `<all_urls>`, доступа к cookies через API, native messaging, `debugger`, внешних сообщений или удалённого исполняемого кода.
- Команды принимаются только от изолированного скрипта этого расширения в основном фрейме официального Omni; запросы привязаны к вкладке и документу отправителя. Произвольные URL и скрипты запрещены. Посещаемость записывается только фиксированной командой `/presents/set-was`: проверяются аккаунт, урок, список учеников и предыдущие отметки; результат перечитывается с сервера. Оценки изменяются отдельной командой `/presents/set-mark`; выдача материалов темы — через `/presents/set-theme`. Разрешена смена преподавателя через `/auth/change-user`: проверяются текущий аккаунт и доступный список Omni, после перезагрузки вкладки подтверждается новый профиль.

В общем header выберите преподавателя в «Работаю от имени». Старые данные очищаются сразу, затем загружаются расписание и группы выбранного преподавателя. При отказе Omni старые данные не выдаются за данные нового пользователя. Если список недоступен, дождитесь загрузки или проверьте доступных преподавателей в официальном Omni.

Для входа под другим логином используйте отдельную кнопку «Сменить аккаунт». После подтверждения расширение очищает текущие данные интерфейса и открывает штатный выход Omni (`/auth/logout`). Дождитесь официальной страницы входа и войдите вручную; расширение автоматически загрузит данные новой сессии. Пароль не вводится и не сохраняется в расширении. Сессия общая для вкладок Omni в этом профиле браузера: смена затронет и их. Если Omni не подтвердил выход, приложение покажет ошибку и не подключится автоматически к прежней сессии.
- Расширение заменяет интерфейс в открываемых страницах Omni; значок расширения использует уже открытую вкладку, если она есть. Cookies общие с текущим профилем браузера. Вход или смена аккаунта могут затронуть другие вкладки Omni; перед показом данных сверяется аккаунт.
- Превью: PDF и изображения без ограничения размера в загрузчике расширения; внешняя загрузка без cookies. Проверяются исходный и конечный URL, перенаправления выполняет браузер. Реальная доступность файлов зависит от хранилища.
- Тема урока выбирается в интерфейсе расширения: список методпакета (`/presents/get-methodpackage-themes`) либо ручной ввод; сохранение через `/presents/set-theme`. Метаданные берутся из свежего урока, выбранная тема сверяется с каталогом. Выдача ДЗ/практической работы — явные флажки с подтверждением. При неопределённом результате нет автоматического повтора запроса.
- Посещаемость — на странице «Мой урок»: три статуса и подтверждаемое «Все присутствуют» для всей группы, включая скрытых поиском учеников. До сохранения темы отметки остаются локальным черновиком. После подтверждённого сохранения темы здесь же урок перечитывается, затем отправляются отметки с новыми идентификаторами посещений. Черновики разделены по аккаунту и уроку, живут в памяти страницы (не переживают её перезагрузку/закрытие). При сбое отправка приостанавливается: загрузите урок, проверьте данные, затем возобновите отправку явно. Не закрывайте интерфейс во время сохранения. Оценки редактируются в соответствующих колонках таблицы.
- Не закрывайте вкладку Omni. При её закрытии нажмите кнопку официального входа заново.

Сборка не является публикацией в магазинах расширений. Установку без режима разработчика и обновления через магазин нужно готовить отдельно.

## Оценки за домашние работы

На вкладке «Домашние задания» оценку можно поставить одной работе (поле в строке) или сразу выбранным. Что важно знать про выставку пакетом:

- **Объём.** За один раз — до 100 работ; выбор действует на все страницы таблицы по текущим фильтрам. Для двух и более работ нужно подтвердить действие. Оценка — целое число от 1 до 12 (см. «Шкала оценок»).
- **Пакет не атомарен.** У Omni нет транзакций, поэтому работы сохраняются по одной, по порядку. До первой записи весь выбор сверяется со свежим списком: если хотя бы одна работа уже проверена или изменилась, **не записывается ничего** («Работа уже проверена или изменилась»).
- **Нагрузка на Omni.** Сначала 2 запроса, затем по 6 на каждую работу (проверка аккаунта, чтение списка, проверка аккаунта, запись, чтение списка, проверка аккаунта). Они идут строго друг за другом, без пауз: для 100 работ это около 600 запросов и заметное время. Рекомендуется выбирать не больше нескольких десятков работ за раз — так меньше нагрузка на Omni и меньше риск остановки посередине.
- **Остановка на первой ошибке, без повторов записи.** Интерфейс показывает «сохранено N из M»; эти N подтверждены перечитыванием. Состояние работы, на которой произошла ошибка, не подтверждено: запись могла пройти. Проверьте её в самом Omni. После ошибки список работ нужно обновить, пока этого не сделано, новые оценки не отправляются.
- **Потеря сессии или смена аккаунта посреди пакета.** Если к этому моменту уже были подтверждённые оценки, их число показывается в сообщении об ошибке, после чего нужно заново подключиться. Если ошибка случилась раньше первого подтверждения, действует обычная обработка: интерфейс предлагает войти заново.
- **Пока идёт пакет**, расширение выполняет только эту команду: остальные (кроме превью файлов и проверки возможностей) получают «Дождитесь завершения предыдущего запроса». Не закрывайте и не перезагружайте вкладку Omni; браузер предупредит о закрытии.
- **Оценка недоступна** для запросов на пересдачу (у них отдельный официальный процесс), для работ без однозначного идентификатора и для работ, у которых статус не допускает оценивания.

## Шкала оценок

- **Домашние работы:** целое число от 1 до 12. Сервер Omni не принимает оценку выше 12; это поведение его API, расширение его не вводит и обойти не может. Граница продублирована в таблице и в протоколе команд, чтобы не отправлять заведомо отклонённые запросы. Другой шкалы расширение для ДЗ не поддерживает.
- **Контрольная и работа на уроке:** поле принимает 1–100. Это техническая граница расширения, а не обещание шкалы для группы: допустимое значение и право записи определяет Omni, а отказ показывается как ошибка.

## Досье преподавателя

Вкладка только для чтения: три запроса `GET` — `/dossier/get-single-data` («Показатели»), `/dossier/get-data-graphics` («Динамика») и `/dossier/get-all-data` («Подробные данные»). Разделы загружаются независимо, ошибка одного не скрывает остальные. Данные загружаются при открытии вкладки и по кнопке «Обновить досье» и живут только в памяти страницы; расширение не записывает их в хранилище. Данные личные: не прикладывайте скриншоты досье к публичным Issues.

Формат ответов Omni не документирован, поэтому фиксированной схемы у вкладки нет: ответ показывается обобщённо и рекурсивно.

- Объект выводится списком «поле — значение»; подчёркивания в именах полей заменяются пробелами. Подписи — это ключи из ответа Omni, а не переведённые названия.
- Вложенный объект становится подразделом. Массив объектов — таблицей, колонки которой объединяют ключи всех строк. Массив значений — списком в одну колонку.
- Пустое значение показывается как «—», логическое — как «Да» или «Нет».
- **Глубина вложенности ограничена 12 уровнями.** Глубже вместо содержимого показывается сообщение «Данные содержат слишком много вложенных разделов».
- **Размер ответа не ограничивается и не разбивается на страницы.** Очень большой ответ отображается целиком, и интерфейс может работать медленнее.
- Если аккаунт сменился между запросами, результат отбрасывается и требуется повторное подключение.

## Проверки

```powershell
npm test
npm run build:extension
npx playwright install chromium
node tests/extension-browser.mjs
```

Браузерный тест устанавливает настоящее расширение в отдельный временный профиль Chromium, но ответы Omni подменяет вымышленными: пароли и реальные данные не используются.
