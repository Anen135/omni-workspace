# Расширение Omni Workspace — Beta

Бета-версия из ветки `main`, дальнейшая разработка — `develop`. Интерфейс поставляется внутри расширения Manifest V3. Не нужны EXE, WebView2, Node.js или сервер на компьютере пользователя. Node.js нужен только разработчику для сборки. Код расширения обновляется заменой пакета, не скачивается с сайта.

## Установка для тестирования

```powershell
npm ci
npm run build:extension
```

1. В Opera откройте `opera://extensions`, в Chrome — `chrome://extensions`, в Edge — `edge://extensions`.
2. Включите режим разработчика и выберите «Загрузить распакованное расширение».
3. Выберите папку `dist-extension` в проекте. Если получили ZIP, сначала распакуйте его.
4. Нажмите значок расширения: откроется наш интерфейс.
5. Нажмите «Открыть официальный вход». Завершите проверку браузера и вход в открывшейся вкладке Omni, затем вернитесь в интерфейс расширения.
6. Оставьте вкладку Omni открытой: через неё выполняются запросы. Это обычная вкладка текущего браузера, не отдельный Edge и не отдельный профиль.

Автотест запускается на Chromium. Ручная совместимость Opera/Edge и реальный вход конкретного аккаунта требуют отдельной проверки. Firefox не поддерживается этим прототипом.

## Разрешения и границы

В текущем коде расписание открывает конкретную дату и пару в «Мой урок». Посещаемость и оценки за контрольную/работу на уроке можно изменять без клиентского ограничения на прошедшее или будущее занятие. Оценки записываются фиксированной командой `/presents/set-mark`; проверяются аккаунт, дата, группа, пара, расписание, ученик, ID посещения и прежняя оценка. Успех подтверждается перечитыванием. Реальные ограничения шкалы и периода остаются за сервером. Нет автоматических повторов записи, удаления оценки или создания фиктивных посещений.

- `scripting`: упакованный адаптер чтения и посещаемости в основной фрейм вкладки `omni.top-academy.ru`, в изолированном мире расширения. Переключение преподавателя выполняется отдельной фиксированной функцией в MAIN: ей нужен доступ к штатной очистке сессии Omni.
- `storage`: хранится только ID созданной вкладки в `storage.session`. Пароли, cookies и учебные данные расширение туда не записывает.
- Доступ к Omni и файловым хранилищам Academy для запросов и превью. Match-пути host_permissions не ограничивают доступ внутри хоста; дополнительная проверка путей есть в коде.
- Нет `<all_urls>`, доступа к cookies через API, native messaging, `debugger`, внешних сообщений или удалённого исполняемого кода.
- Команды принимаются только от собственной страницы `index.html`. Произвольные URL и скрипты запрещены. Посещаемость записывается только фиксированной командой `/presents/set-was`: проверяются аккаунт, урок, список учеников и предыдущие отметки; результат перечитывается с сервера. Оценки изменяются отдельной командой `/presents/set-mark`; выдача материалов темы — через `/presents/set-theme`. Разрешена смена преподавателя через `/auth/change-user`: проверяются текущий аккаунт и доступный список Omni, после перезагрузки вкладки подтверждается новый профиль.

В общем header выберите преподавателя в «Работаю от имени». Старые данные очищаются сразу, затем загружаются расписание и группы выбранного преподавателя. При отказе Omni старые данные не выдаются за данные нового пользователя. Если список недоступен, дождитесь загрузки или проверьте доступных преподавателей в официальном Omni.

Для входа под другим логином используйте отдельную кнопку «Сменить аккаунт». После подтверждения расширение очищает текущие данные интерфейса и открывает штатный выход Omni (`/auth/logout`). Дождитесь официальной страницы входа и войдите вручную; расширение автоматически загрузит данные новой сессии. Пароль не вводится и не сохраняется в расширении. Сессия общая для вкладок Omni в этом профиле браузера: смена затронет и их. Если Omni не подтвердил выход, приложение покажет ошибку и не подключится автоматически к прежней сессии.
- Уже открытые чужие вкладки Omni не захватываются: расширение создаёт свою вкладку, но cookies общие с текущим профилем браузера. Вход или смена аккаунта могут затронуть другие вкладки Omni; перед показом данных сверяется аккаунт.
- Превью: PDF и изображения до 8 МБ; внешняя загрузка без cookies. Проверяются исходный и конечный URL, перенаправления выполняет браузер. Реальная доступность файлов зависит от хранилища.
- Тема урока выбирается в интерфейсе расширения: список методпакета (`/presents/get-methodpackage-themes`) либо ручной ввод; сохранение через `/presents/set-theme`. Метаданные берутся из свежего урока, выбранная тема сверяется с каталогом. Выдача ДЗ/практической работы — явные флажки с подтверждением. При неопределённом результате нет автоматического повтора запроса.
- Посещаемость — на странице «Мой урок»: три статуса и подтверждаемое «Все присутствуют» для всей группы, включая скрытых поиском учеников. До сохранения темы отметки остаются локальным черновиком. После подтверждённого сохранения темы здесь же урок перечитывается, затем отправляются отметки с новыми идентификаторами посещений. Черновики разделены по аккаунту и уроку, живут в памяти страницы (не переживают её перезагрузку/закрытие). При сбое отправка приостанавливается: загрузите урок, проверьте данные, затем возобновите отправку явно. Не закрывайте интерфейс во время сохранения. Оценки редактируются в соответствующих колонках таблицы.
- Не закрывайте вкладку Omni. При её закрытии нажмите кнопку официального входа заново.

Сборка не является публикацией в магазинах расширений. Установку без режима разработчика и обновления через магазин нужно готовить отдельно.

## Проверки

```powershell
npm test
npm run build:extension
npx playwright install chromium
node tests/extension-browser.mjs
```

Браузерный тест устанавливает настоящее расширение в отдельный временный профиль Chromium, но ответы Omni подменяет вымышленными: пароли и реальные данные не используются.
